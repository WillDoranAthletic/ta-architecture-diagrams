1. Mobile push (APNS + FCM)

Iterable and MEMO story push paths. Both editorial entry points (WP Push Tool V3 and Hub admin via Apollo) feed into this section. All excluded mechanisms (Hermes, MEMO game push, Slide Story, Live Rooms, Podcast, V1 legacy, MIS /story-campaign bridge) are documented in section 6.

2. Email

Three recurring digest types (US Daily, Weekly, UK Daily) plus Targeted Sends, Pickem, and editorial proofs — all landing in Iterable. Two dispatch mechanisms (Airflow → SQS → Lambda, and PHP cron → DJJob → direct curl) run in parallel; a datamart sync bridges DS output into the PHP path. US Daily is fully DS-Airflow; Weekly is HYBRID (Airflow DAG + PHP cron, mid-migration); UK Daily is entirely PHP (no DS model yet). See the Newsletters Coda page for full context.

3. In-app realtime (Apollo Subscriptions)

WebSocket transport over wss://api.theathletic.com/gqlsubscriptions. 14+ channels; Redis PubSub backplane.

4. Device widget (iOS / Android Live Activities)

Background widget updates via APNS Live Activity channel. Not user-facing notifications, but still content push to the device.

5. Outbound partner webhooks

Only partner push found in the repos: article publish events to NYT PubP syndication gateway.

6. Documented absences

Capabilities the codebase does not have, or has as dead code.

  • Not implementedSMS / Twilio / SNS SMS. No provider credentials, no senders. The only SNS topics in prod tfvars are PagerDuty-bound for internal alerting.
  • Dead codeIterable comment-reply campaign 560282 (class.iterablePush.inc.php:27). Class method exists, no callers for comment replies. iterablePush is still live for story pushes.
  • DormantAWS SES helper (theathletic-serverless/src/helpers/emailSender.ts). No Lambda imports it; Iterable is the sole email provider.
  • Dormant candidatedaily_digest_algo_no_follows Airflow DAG last commit 2025-10-07 with message "default to void queue", may be disabled. Pending CRM team confirmation.
  • DormantnotifySitemapUpdate Lambda. Google sitemap ping endpoint was deprecated by Google in 2023. Separately flagged for retirement in the Destinations page.
  • Out of scopeHermes social notifications (comment replies, mentions, comment-likes). User-to-user Fan Platform push, not content push. Swift service on ECS/Fargate, enqueued via SQS production-compass-push-queue, NYT-owned. Captured in ~/claude/push-notification-delivery.md and Push notifications under Stride.
